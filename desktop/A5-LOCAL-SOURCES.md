# A5 local prepared package provider

This isolated build adds a normal-main native directory picker to the existing S5 results page. It does not create analysis drafts, copy/export artifacts, download results, load RData, or verify science.

Choose **Open local result packages → Authorize local result package folder**. Select exactly one prepared directory containing `signet-package.json`. Cancel changes no catalog, package index or selection. The picker is the authority boundary; there is no renderer-supplied path/grant API. Revoke selected or unavailable source access from the same page. Revocation persists; reauthorizing after revocation creates a different token. Registered packages and saved artifact references remain on disk but are blocked while their old authority is unavailable.

The declaration has exactly `{schemaVersion:1,kind,label,manifest}`. `kind` is `external` or `synthetic`; `label` is a nonempty printable string ≤80 characters. `manifest` is the existing schema documented in `core/s5/README.md`: sourceId/batchId/revision, fixed column/source→row/target direction, axes, claims, visualization and artifact declarations. The broker does not accept complete/internal-run/verified flags. Every declared artifact must exist and match size/hash before approval. Existing S5 schema/parse rules still apply, including 32 entries, 4 MiB/file, 16 MiB/package and 1024 axes/1 Mi cells. Unknown fields or source versions fail closed. A matrix-only declared package can be read without a trusted scientific session.

The declaration is a regular non-symlink UTF-8 file ≤64 KiB. The serialized authority item must also fit 64 KiB and the whole authority 512 KiB. Eight non-revoked references and 128 lifetime catalog entries maximum; no automatic scan, eviction or history traversal. Roots/ancestors/artifacts/declaration/catalog cannot be symlinks. Runtime/state roots and source roots must be separate according to the existing S5 checks; selecting `/`, an ancestor of runtime, or provider state is refused.

Main owns `runtime/s5/provider/catalog.json` (bounded, checksummed atomic replacement), storing opaque random token, approved canonical path, directory device/inode, declaration hash and revocation. No artifact bytes are copied into this catalog. Cold startup fully validates every non-revoked source before providing worker grants; invalid sources stay blocked until explicit reauthorization. The selected/index metadata cannot grant source access. The renderer receives only tokens, labels and package metadata, never roots/grants; source errors are sanitized to finite codes. The separate native source API has exact frame/URL/formal-mode and 16 KiB single-argument guards.

Main serializes package actions and native dialogs; mode generation is checked before dispatch and before approval commits. The worker serializes a trusted internal authority replacement message with monotonic revision beside existing S3/S4/S5 requests, replacing only the Packages adapter. It does not stop/recreate the worker or change other stage controllers. Package/index/selection storage is unchanged. The existing eight renderer methods cannot invoke this internal message. Worker grant resolution rechecks pinned declaration bytes and directory identity before/after package snapshot work; each artifact is still reread and hashed by PackageIndex. Revocation completes after queued earlier work and prevents subsequent old-token requests. Reads and revoked/changed sources do not overwrite selected refs.

`provider.lock` is held by the main owner and released on normal exit. Unknown/stale locks are not stolen or automatically repaired. Runtime and approved roots remain host-trusted; path-based Node checks are not OS directory-handle confinement and do not promise protection from an adversary rewriting trusted ancestor directories between system calls. Catalog/selection/index are separate atomic files, not one cross-file transaction. Crash after a catalog write but before worker acknowledgment may require reopening/rechecking; it is not reported as package registration or selection success.

Run `node --test desktop/test-a5-provider.cjs` from repository root (or `npm run test:a5` in desktop). Set `SIGNET_A5_TEST_ROOT` to a canonical dedicated evidence runtime to retain test materials. Independent acceptance, actual native user interaction, real scientific data/session/HPC operation remain separate. Controlled hidden-main tests replace only native dialog results; they do not inject a Service authority.
