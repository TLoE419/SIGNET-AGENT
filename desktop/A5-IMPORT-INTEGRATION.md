## User flow and authority

Authorize a prepared local package, register its verified bytes, enter finite label/notes, explicitly select TCGA/GTEx or leave cohort unknown, choose freq/ntop, then Confirm and create. Main presents a native confirmation (Cancel default) stating cohort and compatibility defaults. Renderer submits exactly packageId/hash/sourceRef/requestId/label/notes/cohort/parameters. It cannot choose a draftId/path/grant/owner/authorizationToken/confirmed flag. Main verifies exact sender/mainFrame/home URL, formal mode generation, source authority sync, worker prepare, and confirmation return. Every live worker grant query rechecks the captured frame/generation and 60-second expiry. Navigation, mode round trips and quit make old captured generations invalid; no durable active grant is restored.

Service uses a private command-ID-correlated worker query/reply outside the serial worker queue. The main-only resolver compares all normalized public request fields for a write, validates owner/token, and grants a stable request-bound grantId. Cold read grants are read-command-scoped and fresh; worker inspect resolves the persisted exact intent and rechecks core source authority, package, sidecar and draft. Renderer-supplied sourceRef never supplies the actual source authority. Stable request token/grant identities only preserve same-request intent recovery; they are not bearer authority without the live main callback.

Cancel never executes or resumes an import; a read-only inspect preserves any historical actualDraftCreated flag. New cancel creates no import intent/draft. Importer partial/null/actual flags and unknown-lock refusal are preserved. Import state is runtime/s5/imports. Discovery scans at most 144 top-level entries, 128 intent files, 64 KiB/file and 2 MiB total, nofollow/stat/read/stat before metadata use. A known intent keeps its draft on the import route even if the stored workflow is tampered; corrupt intent discovery fails closed instead of exposing a bare schema draft. List discovery is shared once per command. No infinite history scans, hidden retries, auto lock stealing, or history deletion.

## Mandatory semantics and legacy isolation

Both imported draft opening and cold general draft lists use fresh Importer.inspect via importView. List rows show unknown or user-selected semantics and source verification; blocked rows show import-unverified and no cohort/tissue defaults as source facts. Imported rows never enter the ordinary editable S1 form. The existing New analysis → Import workflow action also routes to controlled packages instead of creating a legacy bare import form. The imported result page shows verified draftRef/revision/content hash, declared cohort, compatibility/user-selected meaning, Lung as schema default and remaining parameterMeaning, source verification/kind, science unknown and session/scientific execution blocked. Opening/rechecking makes a new controlled load/inspect; null never falls back to bare Drafts.load/list or cached successful data. Legacy import drafts with no unique intent are visibly unverified and cannot enter bare S1 editing/opening.

Raw Drafts schema1/defaults/hash remain unchanged; the exact stored draft is only carried together with semantics in importView. No input matrix is renamed expression/genotype and no provenance is inferred. Legacy draftSave refuses import payloads and any rewrite of a guarded import ID, preventing a raw-save bypass. General non-import drafts retain existing behavior. Existing native export paths, authorizer and exporter are retained; original export tests remain unchanged. The adapter removes only the fulfilled formal_import_adapter missing item from its outward report; trusted_session_generation/load and all compute/session/legacy workflow guards remain blocked.

## Checks and limits

Run npm run test:a5-import in desktop (supply a new owned SIGNET_IMPORT_TEST_ROOT and SIGNET_IMPORT_INTEGRATION_TEST_ROOT). Existing affected regression is run once in the evidence suite, with originals unchanged. Scripted hidden normal-main evidence uses only owned synthetic roots; it substitutes native dialog returns and drives DOM/closed preload APIs. It does not prove human native interaction, real user data, remote execution, R/session/scientific success or original-root deployment.

These remain protected-ancestry Node path checks and checked snapshots, not OS anchored-directory isolation or cross-file transactions. Runtime/intent journals must remain protected and retained. A pending command has a bounded timeout and may need explicit same-request status/reconciliation; no blind retry or inference of zero side effects after unknown failure. Pre-existing natural source refusal observations remain open; preserve any new natural refusal evidence without weakening time/hash/inode guards.
