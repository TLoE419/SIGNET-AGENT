This pending identity is not an executed scientific analysis, an accepted Registry record, or a session reference. ## Navigation and lifecycle

Frame navigation and redirects use Host's parsed exact origin, not URL prefix approval. Main navigation is denied; popups are always denied, including owned-origin popups. Open in browser has a separate no-argument command using only the currently held owned URL after revalidation. HTTP/data/WebSocket requests are admitted only at the exact ready loopback host/port; ws maps to the same owned HTTP origin, wss/https/aliases/credentials/other ports/file are refused. All navigation/redirect/request gates run on every event; they are not declarations that an R server's own outgoing traffic is contained.

Mode changes, main navigation, close and quit revoke URL authority immediately. before-quit prevents immediate exit and performs bounded owned shutdown before ending the monitor worker; cleanup uncertainty remains journaled, never represented as a successful process stop. Independent analyses/other services are untouched. Imported result UI provides open/status/close and distinguishes service-only from official-page/scientific acceptance. It embeds only a current ready URL; default normal-main view stays blocked.

## Real process engineering, not a service provider

helper-lease.cjs is a private controlled non-network helper seam, not installed into normal main. A synchronous logical lease precedes launch in ready. It journals owner/token/logical birth, then the actual spawned PID and explicit unknown OS birth, then actual OS ps lstart and command-token fingerprint. The logical UUID never serves as OS birth evidence. Its ready result says listening=false/httpOk=false/url=null; Host must reject it with READY_UNVERIFIED and still clean the exact child.

Stopping requires captured child, same owner/token/birth, command token and identical current OS birth fingerprint, then waits for the observed owned exit. Failed proof/cleanup retains the reference and blocks; cold instances do not kill a PID from a saved file. The accepted adapter's own journal remains explicitly logical/pid=null; the helper's separate actual-process journal is linked by the same lease identity. No arbitrary commands/PIDs/paths are exposed to renderer, no unknown-owner reconciliation or real R process provider is installed.
